# 山姆蛋 POS 收銀（Windows 桌面版）

門市收銀系統的獨立 Windows 程式。收銀系統整個包在程式裡，不需要網路，也不會連到任何網站。

網頁版在 <https://samtss.com/tools/pos/>，功能相同。

## 下載

到這個專案的 [Releases](../../releases/latest) 頁面下載：

| 檔案 | 適合 |
|---|---|
| `SamEggPOS-Setup-版本.exe` | 安裝到電腦，桌面和開始功能表會有捷徑。一般建議用這個。 |
| `SamEggPOS-版本-portable.exe` | 免安裝，點兩下直接開。適合先試用。 |

需要 64 位元的 Windows 10 或 Windows 11。

### 第一次執行會看到警告

這個程式沒有購買數位簽章，Windows 會顯示「Windows 已保護您的電腦」。按「其他資訊」，再按「仍要執行」就能開啟。

## 功能

- 收銀：點商品或掃條碼、單品與整單折扣、會員點數、掛單取單、現金找零、分開付款、統一編號與手機條碼載具
- 訂單：查詢、重印明細、部分或全部退貨
- 登入：每次打開先選門市和收銀員（這是選擇，不是密碼）
- 商品與庫存：分類、品牌、進貨廠商、CSV 匯入匯出、進貨、盤點、異動紀錄
- 多門市：每家門市的倉庫庫存分開記，可並排查看、依門市／類別／品牌／廠商篩選，門市之間調撥；交班與日結也分門市
- 優惠：買一送一、限時折扣、禮包價、0 元贈品、會員等級折扣
- 會員：集點與消費紀錄
- 交班與日結：對現金、日結報表依付款方式列出金額，可查看與下載任何一天
- 報表：銷售額、收款方式、分類與商品排行
- 列印交易明細、交班表與日結表（58 mm、80 mm 熱感紙或 A4）
- 設定分頁：門市、收銀、付款方式、員工與權限（PIN、店長授權）、明細列印、金額與稅、會員、庫存、外觀、資料備份
- 閒置自動鎖定、超過幾天沒備份會提醒

快捷鍵：`F2` 搜尋商品、`F4` 結帳、`F11` 全螢幕。USB 或藍牙掃描槍在收銀畫面直接掃就可以。

## 資料存在哪裡

- 所有商品、訂單、會員與設定都存在這台電腦的 `%APPDATA%\SamEgg POS` 資料夾。
- 和瀏覽器無關：清除 Chrome 或 Edge 的瀏覽資料不會影響這個程式。
- 從選單「檔案 → 開啟資料存放的資料夾」可以直接打開。
- 資料不會上傳，也不會和其他電腦同步。**重灌或換電腦前，請先到「設定」下載備份檔**，到新電腦後再用「從備份檔還原」。
- 解除安裝不會刪除資料。要完全清除，請手動刪掉上面那個資料夾。

## 更新

下載新版的安裝檔直接安裝，或換成新版的免安裝檔，原本的資料會保留。更新前建議先下載一份備份檔。

程式不會自己檢查更新。

## 請注意

- 列印的是交易明細，不是統一發票，沒有連接財政部電子發票平台。統一編號與載具只檢查格式並記在訂單上。
- 信用卡、電子支付等付款方式只是記錄「客人用什麼付」，不會連接刷卡機或任何支付服務。
- 金額以整數元計算。

## 自己打包

需要 Node.js 22。

```bash
npm ci
```

```bash
npm test
```

```bash
npm start
```

```bash
npm run dist
```

`npm run dist` 要在 Windows 上執行，產生的檔案在 `dist/`。推送 `v1.0.0` 這種標籤時，GitHub Actions 會自動打包、啟動檢查，並發布到 Releases。

## 檔案

| 路徑 | 說明 |
|---|---|
| `main.cjs` | 視窗、選單、`app://pos/` 位址與啟動檢查 |
| `resolve.cjs` | 把 `app://pos/…` 對應到 `app/` 裡的檔案，擋掉資料夾以外的路徑 |
| `app/` | 收銀系統本身，由網站專案的匯出腳本產生，請勿手動修改 |
| `app/fonts/` | 內建字型 Noto Sans TC 與 Space Grotesk，依 SIL Open Font License 授權，授權條款在同一個資料夾 |
| `build/icon.png` | 程式圖示 |
